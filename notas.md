# Notas de Git

A continuación, tres comandos de Git que aprendí durante la práctica:

1. **git status** – Permite ver el estado actual del repositorio y los archivos modificados.
2. **git add .** – Agrega los cambios al área de preparación para luego hacer commit.
3. **git push ** – Envía los commits realizados al repositorio remoto en GitHub.
